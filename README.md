# Учебные проекты SkillFactory

В этом репозитории собраны исходники моих учебных работ по Python, ООП, Django, FastAPI, JavaScript и React. **Все работы выполнены без помощи ИИ** во время обучения в SkillFactory. Каждый проект лежит в своей папке; исходные репозитории сохранены для истории разработки.

## О переносе

Код перенесён из отдельных учебных репозиториев. Из снимков исключены виртуальные окружения Python, `node_modules`, файлы блокировки npm, сгенерированные сборки, журналы, локальные базы данных и дамп БД. Встроенные ключи и пароли заменены на переменные окружения; прежние значения из истории исходных репозиториев нужно отозвать.

Для запуска отдельных приложений смотрите README и конфигурацию в соответствующей папке. [Основной профиль GitHub](https://github.com/Mladsii) содержит также AI-проекты.
