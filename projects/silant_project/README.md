# Силант — учёт техники и сервисного обслуживания

**Учебный проект SkillFactory, выполненный без помощи ИИ.** Веб-приложение для учёта машин, технического обслуживания и рекламаций. Проект объединяет API, базу данных, административную часть и интерфейс пользователя.

## Что есть в проекте

- **Публичный поиск машины** по заводскому номеру с ограниченным набором сведений для гостя.
- **Машины:** просмотр, создание и изменение записей; фильтры по номеру и характеристикам техники.
- **Техническое обслуживание:** записи о типе работ, дате, наработке, заказ-наряде и сервисной компании.
- **Рекламации:** регистрация отказов, способа ремонта, запчастей, даты восстановления и времени простоя.
- **Роли:** менеджер, клиент и сервисная компания. API ограничивает доступ к данным и операциям с учётом роли пользователя.
- **Справочники:** модели и узлы техники, типы обслуживания, причины отказов и другие значения для форм.
- **Авторизация:** вход с выдачей JWT-токена; защищённые маршруты API и страницы интерфейса.
- **Интерфейс:** страницы входа, поиска, списка и карточки машины, обслуживания и рекламаций; формы редактирования.

## Стек и структура

| Часть | Назначение | Технологии |
| --- | --- | --- |
| [`api/`](api) | REST API, модели, схемы, маршруты и авторизация | FastAPI, SQLAlchemy, Pydantic, JWT |
| [`silant_project/`](silant_project), [`equipment/`](equipment), [`users/`](users) | Django-проект, модели и административная часть | Django |
| [`silant-frontend/`](silant-frontend) | Пользовательский интерфейс | React, Vite, React Router, Material UI, Axios |

FastAPI предоставляет документацию по адресу `/docs`. Django используется отдельно для административной части.

## Локальный запуск

Нужны Python, PostgreSQL и Node.js. В репозитории нет готового единого Docker Compose; компоненты запускаются отдельно.

1. Создайте базу PostgreSQL и пользователя. Настройте подключение Django в `silant_project/settings.py` под своё локальное окружение. Для FastAPI задайте `DATABASE_URL`, а для JWT — `SECRET_KEY` в переменных окружения или локальном `.env`.
2. Установите зависимости Python: `pip install -r requirements.txt`.
3. Примените миграции Django: `python manage.py migrate`. Учебный дамп базы в общий репозиторий не переносился.
4. Запустите API: `uvicorn api.main:app --reload --port 8000`.
5. Если нужна Django-админка, запустите её отдельно: `python manage.py runserver 8001`.
6. Запустите интерфейс из `silant-frontend/`: `npm install`, затем `npm run dev`. По умолчанию Vite использует порт 5173.

Интерфейс обращается к API по адресу `http://127.0.0.1:8000`; разрешённый origin для разработки указан в `api/main.py`.

## Статус

Это учебная реализация. Перед использованием вне локальной среды нужно вынести локальные настройки и секреты из исходников, проверить права доступа на всех экранах и настроить развёртывание. В текущей версии клиентская проверка роли в `PrivateRoute` содержит демонстрационное значение `manager`; разграничение данных на API реализовано отдельно.
